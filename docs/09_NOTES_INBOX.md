This is the **developer's inbox** for new ideas and changes.

### For the Developer:
Paste new notes (Hebrew or English) into the **UNPROCESSED** section below. That's it.

### For the Agent:
When you see unprocessed notes:
1. **Extract** everything from the UNPROCESSED section
2. **Translate** if in Hebrew
3. **Sort** each note to the correct architecture doc (create new sections like 10.1, 13.2 etc. if needed)
4. **Update** the relevant doc(s)
5. **Move** processed notes to the PROCESSED table below with date + destination
6. **Update** `14_ROADMAP_TRACKER.md` if any phases are affected
7. **Update** `ARCHITECTURE.md` build log

### Rules:
- Never delete processed notes — move them to the PROCESSED table
- If a note contradicts an existing doc, the NEW note wins (latest decision)
- If a note is unclear, add it to PROCESSED with a ⚠️ flag and note what needs clarification
- If a note belongs to multiple docs, list all destinations
